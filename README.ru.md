# StoryEditor

**StoryEditor** — настольный редактор для Windows, предназначенный для просмотра, декомпиляции, редактирования и повторной сборки данных Osiris Story из классической игры **Divine Divinity**.

Проект объединяет WPF-редактор, декомпилятор бинарного Story и процесс сборки с использованием оригинальной 32-разрядной OsirisDLL.dll из собственной установки игры пользователя.

> **Статус:** кандидат MVP 1.0.0. Разработчик подтвердил, что собранный из декомпилированного исходника Story работает в игре. Для окончательного релиза ещё требуется полный тест single-file пакета после чистой распаковки, включая декомпиляцию и сборку.

## Основные возможности

- **Декомпиляция бинарного Story:** чтение файлов .000 / .001 и восстановление редактируемого исходника .div.
- **Навигация по Goals:** просмотр иерархии Goals и разделов INIT, KB и EXIT.
- **Редактирование правил:** просмотр IF и PROC, изменение условий и действий, структурная проверка перед применением.
- **Сохранение исходного форматирования:** по возможности сохраняются нетронутые участки исходника, пробелы, комментарии и форматирование.
- **Перекрёстные ссылки:** поиск правил и использований по всем Goals.
- **Symbol Explorer:** просмотр объявленных API-символов, Story-процедур и неразрешённых вызовов.
- **Goal Links:** анализ явных ссылок на состояния Goals, вызовов Story-процедур и отдельно помеченных эвристических связей.
- **Сборка и слияние:** компиляция исходника оригинальной OsirisDLL и слияние с выбранным базовым Story.
- **Безопасная работа с файлами игры:** редактор не перезаписывает установленные игровые Story-файлы.

## Требования

### Для запуска готовой программы

- Windows 10/11, 64-разрядная версия.
- Легальная установленная копия Divine Divinity.
- Оригинальные файлы игры OsirisDLL.dll и main\startup\story.000.
- Отдельная установка .NET Runtime не требуется: пакет для Windows x64 является self-contained.

### Для сборки Story

Оригинальная Osiris DLL — **32-разрядная** библиотека. Поэтому сборка выполняется через 32-разрядный Windows PowerShell:

    %WINDIR%\SysWOW64\WindowsPowerShell\v1.0\powershell.exe

Обычно он уже присутствует в 64-разрядной Windows. StoryEditor не включает и не распространяет игровую DLL или игровые данные: пользователь указывает собственную установку игры.

### Для сборки StoryEditor из исходников

- Windows 10/11.
- .NET 8 SDK.
- Подключение к интернету при первом восстановлении NuGet-зависимости AvalonEdit.

## Установка

1. Скачайте архив для Windows x64 со страницы Releases на GitHub.
2. Распакуйте архив в каталог, к которому у пользователя есть доступ.
3. Запустите StoryEditor.exe.
4. При первом запуске нажмите **Game installation...**, если редактор не обнаружил игру автоматически.
5. Укажите файл OsirisDLL.dll из каталога игры. Если потребуется, отдельно укажите базовый файл main\startup\story.000.

Настройки установки сохраняются здесь:

    %LOCALAPPDATA%\StoryEditor\game-installation.json

При чтении настроек из старого каталога StoryEditor2 редактор переносит их в новый каталог. Для обычной работы права администратора не требуются.

## Типичный рабочий процесс

### 1. Декомпиляция бинарного Story

1. Запустите StoryEditor.
2. Нажмите **Decompile Story...**.
3. Выберите бинарный Story, например установленный main\startup\story.000.
4. Укажите путь для сохранения восстановленного файла .div.
5. Перед сохранением редактор проверит, что бинарник прочитан полностью и все восстановленные правила назначены.
6. Полученный исходник автоматически откроется в редакторе.

Входной бинарный файл используется только для чтения и не изменяется.

### 2. Просмотр и редактирование

- Выберите Goal в дереве слева.
- Переключайтесь между разделами INIT, KB и EXIT.
- Используйте список правил для перехода к IF и PROC.
- Изучайте связи и использования через Cross References, Goal Links и Symbol Explorer.
- Применяйте изменения правил через встроенную проверку.
- Сохраняйте результат в отдельный файл .div.

### 3. Сборка отдельного бинарного Story

1. Убедитесь, что выбрана правильная установка игры.
2. Откройте изменённый исходник .div.
3. Нажмите **Build game story...**.
4. Выберите новое имя выходного файла.
5. StoryEditor запускает оригинальную 32-разрядную OsirisDLL, компилирует исходник, объединяет результат с выбранным базовым Story и выполняет структурную проверку загрузки в режиме чтения.

По умолчанию результаты сборки сохраняются в:

    %USERPROFILE%\Documents\StoryEditor\Builds

Выходной файл должен быть отдельным. StoryEditor отказывается перезаписывать входные файлы и не устанавливает результат в игру автоматически. Перед ручной заменой игровых файлов обязательно сделайте резервную копию.

## Output и диагностика

Панель **Output / diagnostics** показывает краткую сводку KB выбранного Goal:

- количество правил IF / PROC;
- количество условий и действий;
- количество вызовов функций;
- число вызовов, совпавших с объявленными API-символами;
- количество и текст диагностик парсера, если они есть.

Неизвестные и неразрешённые имена вызовов — это **кандидаты для проверки**, а не автоматически синтаксические ошибки. Полный список доступен в **Symbol Explorer → Unresolved calls**. Парсер пока является консервативной реализацией и не выполняет полную семантическую проверку Osiris или проверку типов аргументов.

## Отдельный CLI-декомпилятор

В репозитории также есть консольный декомпилятор.

Декомпиляция бинарника:

    dotnet run --project .\StoryDecompiler\StoryDecompiler.csproj -- --decompile <story.000> <output.div>

Экспорт структуры Rete в диагностический JSON:

    dotnet run --project .\StoryDecompiler\StoryDecompiler.csproj -- --dump-rete <story.000> <output.json>

CLI и WPF-приложение используют общую библиотеку StoryDecompiler.Core.

## Сборка из исходников

Из корневого каталога репозитория:

    dotnet restore .\StoryEditor.sln
    dotnet build .\StoryEditor.sln -c Release

Публикация автономного single-file приложения для Windows x64:

    dotnet publish .\StoryEditor\StoryEditor.csproj -c Release -p:PublishProfile=win-x64

Профиль публикации находится в StoryEditor\Properties\PublishProfiles\win-x64.pubxml. Результат появится в каталоге проекта bin\Release\net8.0-windows\win-x64\publish.

PowerShell-скрипты встроены в EXE. При запуске сборки StoryEditor извлекает их в %LOCALAPPDATA%\StoryEditor\Scripts. Оба скрипта должны находиться рядом, поскольку основной скрипт вызывает скрипт проверки.

## Структура репозитория

    StoryEditor.sln
    StoryEditor/
      WPF-приложение, интерфейс, настройки игры и профиль публикации
    StoryEditor.Core/
      Лексер, парсер структуры исходника, каталог Goals и парсер правил
    StoryDecompiler.Core/
      Общий бинарный reader, восстановление Rete и генератор DIV
    StoryDecompiler/
      Отдельный консольный декомпилятор
    scripts/
      Исходники PowerShell-скриптов, встроенных в WPF-приложение

Внутренние пространства имён C# пока сохраняют префикс StoryEditor2 для совместимости. Пользовательское название продукта, имя сборки и исполняемого файла — **StoryEditor**.

## Известные ограничения

- Парсер является консервативной реализацией, а не полной грамматикой Osiris или семантическим анализатором.
- Некоторые вызовы движка могут отсутствовать в текущем каталоге API. Неразрешённые вызовы являются подсказками для проверки.
- Анализ перекрёстных ссылок и отношений Goals выполняется на уровне исходного текста; эвристические связи помечаются отдельно.
- Автоматический поиск Steam/GOG ограничен известными каталогами и данными реестра/библиотек. Он не проверен на всех вариантах установки.
- В MVP перенесены не все возможности старого WinForms-редактора.
- Сам редактор публикуется для Windows x64. Для оригинальной Osiris DLL по-прежнему нужен 32-разрядный процесс.
- Перед окончательным выпуском требуется полный тест итогового GitHub ZIP-архива на чистой распаковке.

## Безопасность и совместимость

- Всегда сохраняйте резервные копии оригинальных игровых файлов и редактируемых Story.
- Не указывайте установленный story.000 в качестве выходного файла.
- StoryEditor использует выбранную DLL и базовый Story как входные файлы для сборки; он не патчит установленную игру автоматически.
- Не распространяйте OsirisDLL.dll, div.exe или игровые архивы. Они не входят в репозиторий и релизный пакет.
- Используйте программу только с игровыми файлами, которыми вы имеете законное право пользоваться.
